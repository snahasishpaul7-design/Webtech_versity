# MediCare Pharmacy Admin

A frontend-only pharmacy administration dashboard built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server. Keep `styles.css` and `app.js` beside it.

## Demo scope

Sign in, registration, password recovery, dashboard navigation, staff enrollment, prescription review, customer search, and security settings run in the browser. Data is local/demo-only; there is no backend or real authentication.
